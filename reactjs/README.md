# reactjs

The React application for [jondunlap.com](https://jondunlap.com), built with [Vite](https://vitejs.dev/) and [Material UI](https://mui.com/).

For full setup, running, testing, building, and deploying instructions, see the [repo root README](../README.md).

## Available Scripts

- `npm start` — Vite dev server at [http://localhost:4000](http://localhost:4000)
- `npm test` — run the test suite with [Vitest](https://vitest.dev/) in watch mode
- `npm run build` — production build, output to `build/`
- `npm run preview` — locally serve the production build from `build/`
- `npm run deploy` — build and publish `build/` to the `gh-pages` branch (deploys [jondunlap.com](https://jondunlap.com))
